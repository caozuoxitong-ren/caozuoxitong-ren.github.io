# 物理领域

## 1. 基础物理
### 1.1 经典力学
- 子领域：牛顿力学、分析力学（拉格朗日/哈密顿体系）、刚体力学、流体力学
- 关键理论：牛顿三定律、能量守恒、动量守恒、角动量守恒
- 应用：天体轨道计算、工程结构分析

### 1.2 电磁学
- 子领域：静电学、静磁学、电路理论、电动力学
- 关键理论：麦克斯韦方程组、洛伦兹力、电磁波传播
- 应用：无线通信、电机设计

### 1.3 热力学与统计物理
- 子领域：经典热力学、平衡态统计物理、非平衡态统计物理
- 关键理论：热力学三定律、玻尔兹曼分布、吉布斯自由能
- 应用：热机效率、相变研究

## 2. 现代物理
### 2.1 相对论
- 狭义相对论：时空相对性、质能方程（E=mc2）
- 广义相对论：引力几何化、黑洞理论、宇宙学模型

### 2.2 量子力学
- 核心理论：薛定谔方程、不确定性原理、量子纠缠
- 扩展分支：量子场论（QED、QCD）、量子信息学
- 实验验证：双缝实验、量子隧穿效应

### 2.3 粒子物理与高能物理
- 标准模型：夸克、轻子、希格斯机制
- 实验装置：大型强子对撞机（LHC）、中微子探测

### 2.4 凝聚态物理
- 研究主题：固体电子结构、超导、拓扑材料
- 理论工具：能带理论、密度泛函理论（DFT）

## 3. 应用物理
### 3.1 天体物理与宇宙学
- 研究方向：恒星演化、暗物质/暗能量、宇宙微波背景辐射
- 工具：射电望远镜、引力波探测（LIGO）

### 3.2 核物理
- 主题：核裂变/聚变、放射性衰变、中子星结构
- 应用：核能发电、医学成像（PET）

### 3.3 光学与光子学
- 分支：几何光学、非线性光学、量子光学
- 技术：激光、光纤通信、全息成像

## 4. 交叉学科
### 4.1 生物物理
- 研究内容：蛋白质折叠、神经信号传导、分子马达
- 方法：单分子操控、荧光标记技术

### 4.2 地球物理
- 主题：地震波传播、地磁场模型、板块运动
- 应用：资源勘探、自然灾害预测

### 4.3 计算物理
- 工具：蒙特卡洛模拟、分子动力学、有限元分析
- 领域：材料设计、气候建模

## 5. 数学工具
- 核心数学：微积分、线性代数、微分方程、张量分析
- 专用工具：群论（对称性分析）、复变函数（量子力学）、拓扑学（凝聚态）

## 6. 关键人物与历史节点
- 经典物理：牛顿（力学）、麦克斯韦（电磁学）、卡诺（热力学）
- 现代物理：爱因斯坦（相对论）、玻尔/薛定谔/海森堡（量子力学）、杨振宁（规范场论）

## 7. 知识图谱关系示例
- 量子力学 → 凝聚态物理（解释材料性质）
- 电磁学 → 光学（光的电磁波本质）
- 统计物理 → 热力学（微观解释宏观现象）
- 相对论 → 宇宙学（大爆炸模型）
